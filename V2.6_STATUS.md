## Updater transition verified

The installed V2.5 build is configured to check `flynndavies234-hub/AI-Research`, while V2.6 uses `flynndavies234-hub/Research-Hub`. GitHub resolves the old repository path to the same current repository ID (`1376194351`) after the rename. The old and new API paths therefore resolve to the same release feed.

Result: no duplicate bridge release is required. Publishing V2.6.0 normally in Research-Hub is the transition path for V2.5. V2.6 and later use the canonical Research-Hub name directly.

Release workflow hardening was also added: syntax checks, the static integration audit, and a tag/package-version match check must pass before publishing.
